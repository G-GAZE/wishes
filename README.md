# Wishes · 众愿

**Wishes** 是一款基于 Tauri 2 和 Vue 3 构建的通用的、高度可自定义的模拟抽卡工具。  
通过 **标签系统** 与 **可组合的逻辑引擎**，让你能够自由配置卡池、卡片与抽卡规则，从而模拟任意游戏的抽卡体验。

> ⚠️ 当前版本：v0.1.0 · 测试发布

## ✨ 核心特性

- **标签驱动** —— 卡片、卡组、卡池与逻辑均可附加标签，便于组织、筛选与扩展。
- **可组合逻辑**(待实现) —— 支持硬编码逻辑与规则链组合，理论上可模拟任何抽卡机制(保底、软保底、大小保底、定轨等)。
- **多卡池管理** —— 一个应用内可同时管理多个卡池，每个卡池拥有独立的 Deck、Logic 与状态(保底计数)。
- **本地优先** —— 所有数据存储在本地，无需网络，支持持久化(SQLite)。
